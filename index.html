What is encodekit?

A headless HTTP service for encoding and decoding data in 10 formats: Base64, Base64URL, Base64Raw, Base32, Base32Hex, Hex, URL, HTML entities, ROT13, and Binary. Designed for AI agents to drive over plain HTTP — no UI, no SDK, just plain text responses.

Principles

Agent IS the Interface

No UI, no SDK. The AI agent is the user. The API is the product.

Plain Text by Default

One labeled, grepable line per record. JSON on demand via Accept header.

Instructive Errors

Every 4xx includes a hint telling the agent what to do next.

Self-Documenting

GET /help returns a one-page operating manual the agent loads at runtime.

Simple Auth

OTP via email → long-lived bearer token. No complex OAuth.

Single Binary

Go, CGO_ENABLED=0, zero external dependencies. Deploys as one file.

MCP Connector

Speaks Model Context Protocol at /mcp for chat client integrations.

Multi-Tenant

Workspaces, audit logs, and short stable handles built in.

Quick Start

# Build
make build

# Run
./encodekit

# Auth
curl -X POST localhost:7700/auth/request -d 'email=user@example.com'
curl -X POST localhost:7700/auth/verify -d 'email=user@example.com&code=123456'

# Encode
curl -H "Authorization: Bearer <token>" \
  -X POST localhost:7700/encode/base64 \
  -d 'data=Hello World'
# → type=base64 input=Hello World output=SGVsbG8gV29ybGQ=

# Decode
curl -H "Authorization: Bearer <token>" \
  -X POST localhost:7700/decode/base64 \
  -d 'data=SGVsbG8gV29ybGQ='
# → type=base64 input=SGVsbG8gV29ybGQ= output=Hello World

API Reference

MethodPathDescription
GET/helpSelf-documenting operating manual
GET/encodingsList supported encoding types
POST/encode/{type}Encode text (body: data=...&save=true)
POST/decode/{type}Decode data (body: data=...&save=true)
GET/operationsList saved operations
GET/operations/{handle}Get a saved operation
DELETE/operations/{handle}Delete a saved operation
GET/auditView audit log entries
POST/mcpMCP JSON-RPC 2.0 endpoint

Supported Encodings

base64

Standard Base64 encoding

base64url

URL-safe Base64 encoding

base64raw

Unpadded standard Base64

base32

Standard Base32 (RFC 4648)

base32hex

Hex Base32 (extended hex)

hex

Hexadecimal encoding

url

URL percent-encoding

html

HTML entity encoding

rot13

ROT13 letter substitution

binary

Binary (8-bit per byte)
